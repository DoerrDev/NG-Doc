# 马上执行

「画到匹配立即执行」让手势在轨迹画到一半、已经和某个手势足够相似时就立刻执行，不必等你松开触发键。

## 设置步骤

1. 在左侧选中配置组，点「新增手势」，或点已有手势的编辑按钮。
2. 录制好轨迹（或滚轮）、选好动作。
3. 在「触发时机」下拉框里选「画到匹配立即执行」。
4. 保存后，在目标窗口按住触发键画一遍轨迹，画到与该手势足够相似的一刻，动作就会执行。

## 使用细节

**什么时候算“匹配到”**：软件在你画的过程中不断拿已经画出的部分和手势比较，相似度达到「相似度阈值」（在「设置」→「触发与识别」里调整）就算匹配。轨迹至少要画出一小段才开始比较。

**执行后继续画会怎样**：同一次按住触发键的过程中只执行一次。动作执行后，你继续画、继续按住都不会再触发，松开触发键时也不会再执行一遍。

**对哪些触发方式有效**：

| 触发方式 | 是否可选「画到匹配立即执行」 |
| --- | --- |
| 右键、中键、侧键等按键轨迹 | 可以 |
| 滚轮手势（含屏幕边角滚轮） | 可以，滚出匹配的滚动方向序列就执行 |
| 轨迹末尾带「终点左键点击」 | 不可以，固定为松手后执行 |
| 边角单击、边角停留 | 不需要选择，下拉框锁定。单击在松开按键时执行，停留在时间到达时执行 |
| 快速截屏与录屏、英语翻译、英语优化、粤拼转换 | 不可以，固定为松手后执行 |

此外，如果同一范围（当前程序的配置组加 Global）内有一个右键手势使用了「终点左键点击」，那么该范围内所有右键手势都会改为松开右键后执行，即使你选了立即执行。这是为了给终点左键点击留出时间。

**适合什么动作**：一次就完成的动作，如关闭标签页、切换桌面、打开程序。滚轮手势在一次连续滚动里也只触发一次，要等滚轮停顿片刻、开始新一轮滚动才会再次触发，所以不适合靠连续滚动反复调节音量这类需要逐格重复的操作。

::: warning 误触风险
立即执行没有反悔的机会。轨迹只画到一半、恰好与另一个手势的前半段相似，就会提前执行。尽量不要让多个手势的开头相同，并留意设置里提示的“轨迹过于相似”。
:::

## 常见问题

**为什么我选了立即执行，还是松手才触发？**
看上面的表格：终点左键点击、截屏录屏、AI 类动作，以及同范围存在终点左键点击的右键手势，都会固定为松手后执行。

想要松手后再判断，见 [松手执行](../timing/on-release)。
