# 松手执行

「松开触发键后执行」是默认的触发时机：按住触发键把轨迹画完，松开后软件才识别并执行动作。

## 设置步骤

1. 新增或编辑手势时，「触发时机」默认就是「松开触发键后执行」，无需改动。
2. 在目标窗口按住触发键画轨迹，画完松开。
3. 松开的一刻软件拿整条轨迹去比较，达到「相似度阈值」的手势才会执行；没有匹配就什么都不做。

## 使用细节

**好处**：软件看的是完整轨迹，而不是画到一半的样子，所以开头相似的手势不会互相抢先触发，误触比 [马上执行](../timing/immediate) 少。

**能不能中途反悔**：轨迹画完松手才会判断，所以画错了可以画一条不匹配任何手势的轨迹再松手，这次就不会执行动作。已有手势匹配时，松手即执行，没有单独的取消键。

**强制松手执行的情况**：下面这些手势不能选立即执行，下拉框会固定显示「松开触发键后执行」。

- 轨迹带「终点左键点击」。界面提示：录制的轨迹含终点左键点击，松开右键后执行。
- 快速截屏与录屏、英语翻译、英语优化、粤拼转换。
- 边角单击和边角停留。这两种不需要画轨迹：单击在松开按键时执行，停留在停够设定时长时执行。

另外，当前程序（加 Global）里只要有一个右键手势使用了「终点左键点击」，同范围内的右键手势都会等到松开右键才执行。

## 两种时机对比

| | 松开触发键后执行 | 画到匹配立即执行 |
| --- | --- | --- |
| 默认 | 是 | 否 |
| 执行时刻 | 松开触发键时 | 画到足够相似的瞬间 |
| 判断依据 | 完整轨迹 | 已画出的部分 |
| 误触风险 | 较低 | 较高，开头相似的手势会抢先 |
| 画错能否取消 | 可以，画到不匹配的轨迹再松手 | 不能，已执行 |
| 适合 | 大多数手势、需要终点左键点击的手势 | 追求速度、轨迹形状很独特的手势 |
