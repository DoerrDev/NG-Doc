# 快速上手

NextGestures 是一个常驻托盘的 Windows 鼠标手势工具。按住鼠标按键画一笔、在屏幕边角滚一下滚轮，或者按一个快捷键，就能打开程序、按下组合键、打开网页、截图贴图，或者把选中的文字交给 AI 处理。

下面用「关闭浏览器当前标签页」做第一个例子，几分钟就能完成。

## 安装

1. 打开 [GitHub Releases](https://github.com/DoerrDev/NextGestures/releases/latest)，下载 Windows 安装包并运行。
2. 启动后，NextGestures 会待在任务栏右下角的托盘里。单击托盘图标打开主窗口。

关闭主窗口只是收回托盘，程序仍在后台运行。要彻底退出，右键托盘图标选「退出」。

## 录制第一个手势

1. 在主窗口左侧导航选「手势」，再在配置组列表里选中「Global」。
2. 点右侧的「新增手势」，在面板顶部填写名称，例如「关闭标签页」。
3. 在「鼠标手势」页点「录制」，按住鼠标右键先向下、再向右画一个「L」，然后松开。录制区会显示你画的形状，「按住」一栏自动选中「右键」。
4. 在下方「动作」里点「发送按键」，再点「录制快捷键」，按下 `Ctrl + W`。
5. 点右下角「保存」。
6. 回到浏览器，打开一个测试标签页，按住右键画出同样的「L」，松开后标签页就会被关闭。

如果没有反应，先确认：左侧导航底部的总开关显示「已启用」；这条手势没有被停用；浏览器没有被设为[交给程序自带手势](./profiles/passthrough)。

::: tip 也可以用键盘触发
同一条手势还可以在「快捷键」页录一个组合键，比如 `F1`。鼠标手势和快捷键共用同一个动作，用哪种方式触发都行。详见[快捷键触发](./triggers/hotkey)。
:::

## 一条手势由什么组成

| 组成部分 | 说明 | 详细介绍 |
| --- | --- | --- |
| 触发方式 | 怎样让它执行：画轨迹、滚滚轮、在屏幕边角单击或停留、按快捷键 | [手势](./triggers/gesture)、[滚轮](./triggers/wheel)、[中键与侧键](./triggers/middle-button)、[边角](./triggers/edge)、[快捷键](./triggers/hotkey) |
| 动作 | 触发后做什么 | [发送按键](./actions/hotkey)、[启动程序](./actions/launch-app)、[区域截图](./actions/screenshot)、[AI 动作](./ai/) 等 |
| 执行时机 | 画到就执行，还是松开按键再执行 | [松手执行](./timing/on-release)、[马上执行](./timing/immediate) |
| 配置组 | 这条手势在哪些程序里生效 | [Global](./profiles/global)、[程序配置组](./profiles/apps) |

## 下一步

- 先认识一下主窗口：看[界面导览](./interface)。
- 想让同一个手势在不同软件里做不同的事：看[程序配置组](./profiles/apps)。
- 想截图、贴图或录屏：看[区域截图](./actions/screenshot)、[贴图](./actions/pin)、[区域录屏](./actions/record)，这些功能装好就能用。
- 想让 AI 帮你翻译、润色选中的文字：先在「AI 动作」页配置 AI 服务，见 [AI 动作：配置与使用](./ai/)。
- 临时不想用手势：看[开关手势与快捷键](./settings/toggle)。
- 遇到问题或有新想法：通过[快速反馈](./settings/feedback)直接发给开发者。
