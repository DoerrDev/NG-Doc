# 界面导览

主窗口分为三块：最左边的导航栏、中间的配置组和手势清单、右边的编辑面板。

![NextGestures 主窗口：左侧导航、配置组、手势清单和编辑面板](/images/ui/main-overview.png){.shot}

<p class="shot-cap">主窗口：左侧导航栏 · 配置组列表 · 手势清单 · 编辑面板</p>

## 左侧导航栏

| 位置 | 内容 |
| --- | --- |
| 上方「手势」 | 手势管理页，旁边的数字是所有配置组里的手势总数 |
| 上方「AI 动作」 | AI 动作页，管理 AI 服务和 AI 动作，见 [AI 动作](./ai/) |
| 下方总开关 | 一键停用或恢复鼠标手势，下面的文字显示「已启用」或「已暂停」，见[开关手势与快捷键](./settings/toggle) |
| 「文档↗」 | 在浏览器里打开本文档 |
| 「设置」 | 打开设置窗口。开发者回复了你的反馈时，这里会出现小圆点 |
| 版本号 | 例如 `v1.2.5`，点击查看发布说明并检查更新；有新版本时出现小圆点，见[版本与更新](./settings/update) |

![左侧导航栏](/images/ui/rail.png){.shot .small}

<p class="shot-cap">左侧导航栏：页面切换在上，总开关、文档、设置和版本号在下</p>

## 配置组列表

「手势」页左边是配置组列表：

- 第一项「Global」对所有程序生效，见 [Global 配置组](./profiles/global)。
- 下面是为单个程序建立的配置组，见[程序配置组](./profiles/apps)。被设为「交给程序自带手势」的程序名旁边会显示禁止图标。
- 每一项后面的数字是该组的手势数量。
- 列表底部的「新增程序」用来添加程序配置组。
- 程序配置组右侧的「…」按钮可以切换使用方式或删除该组。

![程序配置组的「…」菜单](/images/ui/profile-menu.png){.shot .mid}

## 手势清单

选中一个配置组后，中间显示它的手势清单，共五列：

| 列 | 内容 |
| --- | --- |
| 轨迹 | 手势形状的缩略图；只设置了快捷键的手势显示一个键盘图标 |
| 名称 | 手势名称 |
| 触发 | 触发键、滚轮方向、边角位置、快捷键等标签；被停用的手势会标出「已停用」 |
| 动作 | 动作内容，例如组合键、网址、程序名或 AI 动作名 |
| 操作 | 停用 / 启用、复制为新手势、删除 |

单击某一行，右侧打开它的编辑面板。

清单上方可能出现两种提示：

- **轨迹冲突**：同一配置组里有手势轨迹过于相似，容易误触发，提示会列出相似的手势，对应行也会标出「轨迹冲突」。处理办法见[手势触发](./triggers/gesture#轨迹冲突)。
- **已交给程序自带手势**：当前程序配置组被设为交给程序自带手势，组里的手势和快捷键暂不生效。

快捷键标签显示为警示样式时，说明这个组合键被别的程序占用了，NextGestures 收不到。

## 编辑面板

右侧编辑面板从上到下依次是：

1. **名称**：面板最上方的输入框。
2. **触发方式**：分「鼠标手势」和「快捷键」两页，页签上显示「已录制」「已设置」或「未设置」。一条手势至少要设置其中一种，也可以两种都设置。
3. **动作**：标题为「动作 · 两种触发共用」，用图标网格选择动作类型。常用动作直接列出，「按键序列」「无」和较多的 AI 动作收在「更多」里。
4. **底部按钮**：已有手势有「停用 / 启用」「删除」「复制为新手势」；右下角是「保存」。

![展开「更多」后的动作图标网格](/images/ui/action-tiles-more.png){.shot .mid}

<p class="shot-cap">动作网格：展开「更多」后可以看到按键序列、无，以及其余的 AI 动作</p>

面板和清单之间的分隔条可以左右拖动，调整面板宽度。

::: tip 记得保存
编辑面板里的改动需要点「保存」才会生效。设置窗口的改动则是自动保存的。
:::
