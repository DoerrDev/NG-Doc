# 程序配置组

除了 Global，你可以为某个程序建立专属配置组，让同一个手势或快捷键在该程序里做不同的事；也可以让某个程序完全不受 NextGestures 影响。

## 设置步骤

1. 点配置组列表底部的「新增程序」。
2. 在「进程名」里填写程序的进程文件名，例如 `photoshop.exe`；或点「拾取窗口」，再点一下目标程序的窗口，进程名和显示名称会自动填好，下方还会显示窗口标题和程序路径供你确认。
3. 需要的话修改「显示名称」，它只用于在列表里显示，留空时用进程名代替。
4. 在「在这个程序里」选择使用方式：
   - **使用 NextGestures 手势**：可以为它单独配置手势和快捷键，没配置的回落到 Global。
   - **交给程序自带手势**：NextGestures 在这个程序里完全不拦截鼠标，见[交给程序自带手势](./passthrough)。
5. 点「保存」。新配置组是空的，选中它，用「新增手势」添加手势。

## 使用细节

- 进程名会自动转成小写保存，匹配时不区分大小写。不填进程名会提示「请填写进程名」。
- 按触发时**前台窗口**（当前正在使用的窗口）所属的程序判断该用哪个配置组，而不是鼠标指针下面的窗口。手势开始时的前台程序会被记下，整个手势过程中不会变。
- 程序有专属配置组时，先匹配专属手势，没有匹配再回退到 [Global](./global)。
- **复制为新手势**：在清单里点某条手势的复制按钮，或在编辑面板底部点「复制为新手势」，会以它为模板打开一条新手势，名称末尾加上「副本」，触发方式和动作原样保留，保存后才生效。适合快速做出相似的手势再改动。

## 「…」菜单

程序配置组右侧有一个「…」按钮，点开后可以：

| 菜单项 | 作用 |
| --- | --- |
| 使用 NextGestures | 恢复使用这个配置组的手势和快捷键 |
| 交给程序自带手势 | 让 NextGestures 在这个程序里不拦截鼠标，组里的手势和快捷键暂不生效 |
| 删除程序 | 确认后删除该配置组及其全部手势 |

![程序配置组的「…」菜单](/images/ui/profile-menu.png){.shot .mid}

当前的使用方式前面有勾选标记。切换立即生效，不需要重启。
