# Global 配置组

Global 是配置组列表里固定的第一项，里面的手势和快捷键在所有程序中都能使用。

## 使用细节

- 在 Global 里新增、编辑、停用手势的方法与其他配置组相同。
- Global 不能删除，也不能设置进程名，它永远对所有程序生效。
- Global 不能设为「交给程序自带手势」。
- 清单里标记为不可删除的手势，删除按钮是灰的。

## 与程序配置组的关系

<ProfileResolve />

当前前台程序有自己的配置组时，NextGestures 按下面的顺序判断：

1. 先只在该程序的配置组里找匹配的手势。找到达到相似度阈值的，就执行它。
2. 程序配置组里没有匹配的手势时，才到 Global 里找。

所以同一条轨迹、同一个触发键在两边都设置了手势时，程序配置组的手势生效，Global 的那条在该程序里不会执行。两边的手势不会合并后一起比较分数。反过来，程序配置组里没有的手势，会自动使用 Global 的，不需要重复设置。

[快捷键触发](../triggers/hotkey)也是一样：同一个快捷键在程序配置组里有绑定就用它的，没有再用 Global 的。

::: tip
想让某个程序有「特别」的行为，就在那个程序的配置组里用同样的触发方式再建一条手势；想在该程序里保持 Global 的行为，什么都不用做。
:::

## 常见问题

**在某个程序里 Global 手势不生效？**
可能是这个程序的配置组里有手势占用了相同的轨迹或快捷键，或者这个程序被设为[交给程序自带手势](./passthrough)。交给程序自带手势的程序里，Global 手势也不会触发。

其他程序的配置见[程序配置组](./apps)。
