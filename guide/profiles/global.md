# Global 配置组

Global 是左侧列表里固定的第一项，里面的手势在所有程序中都能使用。

## 使用细节

- 选中 Global 后，主界面副标题显示「所有程序生效」。
- 在 Global 里新增、启用、停用手势的方法与其他配置组相同。
- Global 不能删除，它没有删除按钮；其中的手势如果标记为不可删除，删除按钮也是灰的。
- 不能给 Global 设置进程名，它永远对所有程序生效。

## 与程序专属配置组的关系

当前窗口所属程序有专属配置组时，软件按下面的顺序判断：

1. 先只在该程序的专属配置组里找匹配的手势。找到达到相似度阈值的，就执行它。
2. 专属组里没有匹配的手势时，才回头到 Global 里找。

所以同一条轨迹、同一个触发键在两边都设置了手势时，专属配置组的手势生效，Global 的那条在该程序里不会执行。两边的手势不会合并后一起比较分数。反过来，专属组里没有的手势，会自动使用 Global 的，不需要重复设置。

::: tip
想让某个程序有“特别”的行为，就在那个程序的配置组里用同样的触发键和轨迹再建一个手势；想在该程序里保持 Global 的行为，什么都不用做。
:::

## 常见问题

**在某个程序里 Global 手势不生效？**
可能是这个程序有专属手势占用了相同轨迹，或者这个程序在 [黑名单](../profiles/blacklist) 里。黑名单里的程序连 Global 手势也不会触发。

其他程序的配置见 [其他配置组](../profiles/apps)。
