# 贴图

贴图是一张浮在所有窗口最上层的图片，适合对照着看资料、临时记一段代码或参数。它可以来自截图，也可以来自剪贴板里的图片或文字。

## 怎样得到一张贴图

- **从截图贴出**：在[区域截图](./screenshot)的编辑状态下按 `Ctrl + T`，或点工具栏的「贴到屏幕」。
- **用「贴图」动作**：给一条手势选「贴图」动作，例如绑定快捷键 `F3`。触发时：

| 情况 | 结果 |
| --- | --- |
| 正在截图编辑 | 把当前选区贴出来，和 `Ctrl + T` 相同 |
| 剪贴板里有新复制的图片 | 贴出这张图片 |
| 剪贴板里有新复制的文字 | 把文字排版成图片贴出。从 Word、WPS、写字板等复制的内容会保留字体、颜色和粗斜体，其他来源按纯文字显示 |
| 剪贴板没有变化 | 从最近关闭的贴图开始，依次恢复关闭过的贴图 |
| 没有可恢复的贴图 | 屏幕上所有贴图短暂变成半透明，提示没有可恢复的内容 |

「贴图」动作固定为松手后执行。

## 基本操作

<PinOps />

贴图默认不透明，边缘带淡蓝色辉光和柔和阴影。点击贴图使它获得焦点后，可以：

| 操作 | 效果 |
| --- | --- |
| 按住左键拖动 | 移动位置 |
| 滚轮 | 以鼠标位置为中心缩放，左上角短暂显示当前比例 |
| 单按 `Ctrl` | 折叠成中央约 64 × 64 像素的小块，再按一次恢复 |
| `Ctrl + C` | 复制图片（含标注） |
| `Ctrl + S` | 保存为 PNG |
| 空格 | 打开编辑工具栏 |
| `Esc`、右键或双击 | 关闭贴图（编辑工具栏未打开时） |

同时最多保留 20 张贴图。

## 编辑工具栏

贴图默认不显示工具栏，按空格打开。工具栏包含：

- 标注工具：矩形 / 椭圆、箭头 / 直线、画笔、记号笔、马赛克、文字、橡皮擦、撤销，用法和快捷键与[截图的标注工具](./screenshot#标注工具)相同；
- 透明度调节；
- 「保存图片」「复制图片」和「完成」。

点「完成」或按 `Esc` 收起工具栏，标注会保留在贴图上。打开工具栏时如果贴图是折叠的，会自动展开。

## 复制和保存的内容

复制、保存得到的始终是完整的原图加上标注，不包含辉光、阴影和工具栏，也不受透明度、缩放和折叠状态影响。

## 恢复关闭过的贴图

关闭的贴图会进入历史记录，可以用「贴图」动作找回：剪贴板没有新内容时，每触发一次就恢复一张，从最近关闭的开始，位置、缩放、透明度和标注都会一起恢复。

- 历史最多保留 20 张，超出时删除最早关闭的一张。
- 原图临时存放在 `%LOCALAPPDATA%\NextGestures\pin-history`，退出 NextGestures 后历史清空。
- 需要长期保留的贴图，请用 `Ctrl + S` 保存。

## 常见问题

**按 `Esc` 没有关闭贴图？** 编辑工具栏打开时，`Esc` 先用来完成编辑、收起工具栏，再按一次才会关闭贴图。

**滚轮变成了调节粗细？** 当前选着标注工具。按 `Esc` 退出工具后，滚轮恢复为缩放。

**触发「贴图」动作，没有贴出刚复制的内容？** 剪贴板里需要是图片或文字。如果复制后又触发过一次贴图，剪贴板就不算「新内容」了，这时会恢复历史贴图。
