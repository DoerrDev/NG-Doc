# 快速翻译

选中一段文字，触发手势后，NextGestures 会把它翻译成中文（原文是中文时则翻译成英文），并在选区旁边的小卡片里显示结果。在动作列表中它叫「英语翻译」。

## 首次使用：配置 AI 服务 {#setup-ai}

「英语翻译」「英语优化」「粤拼转换」都属于 QuickFormater 插件，需要先启用插件并填写 AI 服务信息：

1. 打开主窗口，进入「设置」，切换到「插件」页。
2. 勾选「QuickFormater 文本处理」。
3. 此时设置里会出现「AI 设置」页，切换过去，填写三项：
   - 「OpenAI 兼容接口地址」：例如 `https://api.example.com/v1`。只写到 `/v1` 这一级即可，程序会自动补全后面的路径；填了完整的 `.../chat/completions` 也可以。不要带问号参数，也不要在地址里写用户名和密码。
   - 「API 密钥」：服务商提供的密钥。如果你的服务不需要密钥，可以留空。
   - 「模型」：服务商提供的模型名称，例如 `your-model-name`。这一项必须填写。
4. 点「保存」。

::: warning 隐私提示
触发这些动作时，你选中的文字会被发送到你填写的 AI 服务。请只使用你信任的服务，并避免选中密码、密钥等敏感内容。
:::

## 设置步骤

1. 完成上面的 AI 服务配置。
2. 在主窗口选中配置组，点「新增手势」，设置好触发方式。
3. 在「动作类型」里选择「英语翻译」，保存。如果选项后面带有「插件未启用」，说明还没有启用 QuickFormater。
4. 在任意程序里选中一段文字，触发这个手势。

## 使用细节

- **取词方式**：程序会替你按一次 `Ctrl + C` 复制选中的文字，所以只能翻译能被复制的文字。读取完成后，你原来的剪贴板内容会被还原。
- **翻译方向**：原文不是中文时翻译成简体中文；原文已经是中文时翻译成英文。保留换行、列表等原有格式。
- **结果显示**：翻译结果显示在选中文字附近的卡片里，不会替换原文。生成过程中文字会逐步出现，卡片底部提示「正在翻译 · Esc 取消」。完成后点「复制」可把译文放进剪贴板，按 `Esc` 或点击卡片外部关闭卡片。
- **处理中提示**：发出请求后，在第一段译文出现之前，选区旁会显示一个转圈提示。
- **同时只能处理一个**：上一个 AI 动作还没结束时再次触发，会提示「已有 AI 动作正在处理，请稍候」。

示例：选中 `Where is the nearest subway station?`，卡片中显示 `最近的地铁站在哪里？`；选中 `今天开会改到下午三点。`，则显示对应的英文。

## 常见问题

**没有选中文字，或选中的内容无法复制。** 会弹出提示「没有选中可复制的文字」，约 2.5 秒后自动消失。

**触发后提示出错。** 卡片会写明原因，常见的有：

| 提示 | 处理办法 |
| --- | --- |
| 请先在插件设置中填写 AI 模型 | 在「AI 设置」填写「模型」 |
| AI 接口地址格式错误 | 检查「OpenAI 兼容接口地址」 |
| 连接 AI 接口失败，请检查地址及网络 | 检查网络和地址 |
| AI 请求超时 | 连接超过 10 秒或整个请求超过 60 秒会超时，稍后重试 |
| 鉴权失败（HTTP 401 或 403） | 检查「API 密钥」 |
| 地址或模型不存在（HTTP 404） | 检查地址和「模型」 |
| 请求受限（HTTP 429） | 稍后重试 |
| 选中的文字过长，请缩短选区 | 选中的内容超过 256 KB，缩短后重试 |

**想翻译成其他语言。** 目前方向固定为上述规则，无法更改。
