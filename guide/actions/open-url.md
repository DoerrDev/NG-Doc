# 打开网址

让手势直接打开一个网址，还能把你选中的文字带进网址里，用来快速搜索。在动作网格里点「打开网址」即可选择。

## 设置步骤

1. 编辑手势，在「动作」里点「打开网址」。
2. 在「网址」一栏填写完整网址，例如 `https://www.example.com`。新建时默认是 `https://www.google.com/search?q={selection}`。
3. 点击「测试」检查是否能正常打开，再点「保存」。

网址会用 Windows 的默认浏览器打开。想换浏览器，请在 Windows 设置的默认应用里修改，NextGestures 里没有单独指定浏览器的选项。

## 用 {selection} 搜索选中的文字

在网址里写上 `{selection}`，触发手势时它会被替换成你当前选中的文字。

工作过程：

1. NextGestures 向当前前台窗口发送一次 `Ctrl + C`，复制你选中的内容。
2. 读取到的文字去掉首尾空白，并自动做网址编码，所以中文、空格、`&` 等字符都可以放心使用，不需要自己转换。
3. 剪贴板里原来的文字会被还原。

最多等待约 0.5 秒来取词。

### 例子

| 想搜索的网站 | 网址写法 |
| --- | --- |
| Google | `https://www.google.com/search?q={selection}` |
| 百度 | `https://www.baidu.com/s?wd={selection}` |
| Bing | `https://www.bing.com/search?q={selection}` |

先在网页或文档里选中一段文字，再做手势，浏览器就会打开搜索结果页。

## 注意事项

::: warning
取词是靠模拟 `Ctrl + C` 实现的，所以没有选中任何文字、或所在程序不响应 `Ctrl + C` 时，`{selection}` 会被替换为空，搜索页会以空关键词打开。另外，如果剪贴板里原本放的不是文字（例如一张图片），取词后不会被还原。
:::

- 网址无法打开时（例如格式不对、系统找不到能打开它的程序），屏幕上会弹出一条简短的错误提示。
- 网址里没有 `{selection}` 时，不会触发取词，直接打开该网址，不会动剪贴板。
- 网址也可以是其他能被 Windows 识别的链接，但日常使用建议填写以 `https://` 开头的完整网址。
