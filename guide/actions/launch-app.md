# 快速打开程序

让一个手势一键启动你选定的程序，例如浏览器、记事本或计算器。界面里的动作类型叫「快速启动程序」。

## 设置步骤

1. 打开主窗口，新增或编辑一个手势。
2. 在「动作类型」下拉框中选择「快速启动程序」。
3. 点击「选择程序」，在弹出的窗口里挑选程序（见下文）。
4. 选中后窗口下方的「已选程序」会显示程序名称。想换一个，点击「更换程序」。
5. 点击「测试」可以立刻启动一次，确认选对了；确认无误后点「保存」。

## 在列表里选程序

点击「选择程序」后会先显示「正在读取程序列表…」，随后出现程序列表，每一项带有图标、名称和路径，按名称排序。

- 顶部的搜索框「搜索程序名称或路径」：输入文字即可筛选，不区分大小写，名称和路径中包含该文字的程序都会保留。
- 单击一项选中，再点「确定」；也可以直接双击某一项完成选择。
- 没有符合条件的程序时显示「没有找到匹配的程序」。
- 读取失败时显示「读取程序列表失败」，点「重新加载」重试。

列表内容来自 Windows 的「所有应用」列表，也就是开始菜单里能看到的程序，既包含传统桌面程序，也包含 Microsoft Store 应用。不在开始菜单里的绿色软件可能找不到。

## 使用细节

- 程序以与你在开始菜单里点击它相同的方式启动。如果该程序已经在运行，是切到已有窗口还是再开一个新窗口，取决于程序自己的设计（有的程序只允许运行一个），NextGestures 不会额外处理。
- 启动失败时，屏幕上会弹出一条简短的错误提示。
- 没有选择程序时「测试」按钮不可用，保存前也会提示「请先选择要启动的程序」。

## 旧版命令迁移

早期版本的手势可能使用「旧版命令」（直接填写程序路径和参数）。这类手势仍然会照常执行，但在编辑时，动作类型会显示为「旧版命令」，并提示「此手势使用旧版命令。选择一个程序即可替换。」。点击「选择程序」选好新程序并保存后，就会自动换成「快速启动程序」。旧命令里的参数不会保留。
