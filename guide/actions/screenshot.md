# 快速截屏与录屏

用手势快速框选屏幕上的一块区域：可以截成一张始终显示在最上层的“贴图”，也可以录成 MP4 或 GIF。

## 启用插件

这两个功能都以插件形式提供，默认需要手动开启。

1. 打开主窗口，进入「设置」→「插件」。
2. 勾选「截图」（区域截图并置顶）和／或「录屏」（区域录屏），保存。
3. 在手势编辑器里为某个手势选择动作「区域截图并置顶」或「区域录屏」。

如果动作已选好但插件没启用，会提示「插件未启用」，动作会保留，启用插件后即可使用。

## 区域截图并置顶

触发手势后，整个屏幕（含多显示器）会变暗，用鼠标左键从一角拖到对角即可选区。

- 松开左键完成选区；选区宽、高都不能小于 16 像素，否则视为未选中，可以重新拖。
- 按 `Esc` 或点鼠标右键取消。
- 选区最大不超过 16384 像素边长，总面积也有上限；过大会提示缩小。
- 同时最多保留 20 张贴图，超过时需要先关闭一部分。

选完后，截图内容立即变成一个带阴影的置顶小窗口，并自动处于选中状态，底部出现工具栏。

### 贴图的基本操作

| 操作 | 效果 |
| --- | --- |
| 按住左键拖动图片 | 移动位置 |
| 滚轮 | 调节不透明度，每格 5，范围约 20%–100%，初始为不透明 |
| 工具栏的减号／加号 | 降低／提高不透明度 |
| `Ctrl + C` 或工具栏「复制图片」 | 把图片（含标注）复制到剪贴板 |
| `Ctrl + S` 或工具栏「保存图片」 | 弹出保存窗口，保存为 PNG，默认文件名为“贴图.png” |
| 空格 | 折叠成中心约 64 × 64 的小块，再按一次恢复原样 |
| 双击图片、`Esc`、右键 | 关闭贴图 |

说明：

- 折叠和半透明只影响屏幕显示，复制和保存得到的始终是完整、不透明的原图。
- 保存窗口没有指定默认文件夹，沿用系统对话框的位置。
- 贴图只有在选中时才显示工具栏；点到别的窗口后工具栏会隐藏，折叠的贴图也不显示工具栏。
- 贴图会在关闭后丢失，需要保留请先保存。

### 标注工具

工具栏上可以在贴图上直接标注，下表快捷键在贴图选中时有效。

| 工具 | 快捷键 | 用法 |
| --- | --- | --- |
| 矩形 / 椭圆 | `Ctrl + 1` | 拖出图形；再按一次切换矩形与椭圆，按住 `Shift` 画正方形／正圆 |
| 箭头 / 直线 | `Ctrl + 2` | 拖出线条；再按一次切换箭头与直线，按住 `Shift` 锁定 45° 角度 |
| 画笔 | `Ctrl + 3` | 自由涂画 |
| 记号笔 | `Ctrl + 4` | 较粗的标记笔 |
| 马赛克 | `Ctrl + 5` | 涂抹处打码 |
| 文字 | `Ctrl + 6` | 点击图片输入文字，支持输入法；`Enter`、点空白处、`Esc` 或右键确定，`Shift + Enter` 换行 |
| 橡皮擦 | `E` | 擦除标注 |
| 撤销 | `Ctrl + Z` | 撤销上一步 |

- 工具栏有 8 种预设颜色（红、橙、黄、绿、蓝、紫、黑、白），也可以点调色板自定义。
- 使用工具时，滚轮改为调节粗细（文字则为字号），不再调节透明度。
- 退出标注：`Esc` 会依次确定文字、取消画到一半的一笔、退出工具，最后一次才关闭贴图；右键则结束当前一笔或文字，没有进行中的内容时退出工具。使用工具时双击和右键不会关闭贴图。
- 选了标注工具后若贴图处于折叠状态，会自动展开。

## 区域录屏

触发手势后，同样先用左键拖选录制区域（规则和截图相同，按 `Esc` 或右键取消）。选定后，区域周围出现蓝色边框，下方出现一个小工具栏：

1. 点击带有当前设置的按钮（默认显示「原始 · 30 FPS」），选择清晰度和帧率。
2. 点「开始录制」，边框变红，按钮变为「停止录制」。
3. 录完点「停止录制」。
4. 在弹出的保存窗口里选择位置和格式，成功后会提示“录屏已保存”和路径。

点工具栏右侧的取消按钮，或按 `Esc`，可放弃录制；录制中取消不会保存任何内容。录制开始后不能再改清晰度和帧率。

### 清晰度与帧率

| 选项 | 说明 |
| --- | --- |
| 720p 流畅 | 画面最大 1280 × 720（竖屏区域相应转置），只缩小不放大 |
| 1080p 高清 | 最大 1920 × 1080，只缩小不放大 |
| 原始分辨率 | 默认值，保持选区原大小，最大 4096 × 4096 |
| 帧率 | 15 / 24 / 30 / 60 / 120 FPS，默认 30 FPS |

### 导出与保存

- 保存窗口的默认文件名是当前日期时间，可选「MP4 视频」或「GIF 动图」，默认 MP4。文件名必须以 .mp4 或 .gif 结尾。
- MP4 保持录制时的画面大小和帧率。
- GIF 是体积较小的预览版：画面最大 854 × 480，约每秒 10 帧，循环播放。
- 录屏只采集画面，不录制声音。
- 同一时间只能进行一个录屏任务。
- 不需要安装 ffmpeg 或其他工具，使用 Windows 自带的媒体功能。

::: warning 注意
如果提示启动编码器失败，可检查系统是否安装了“媒体功能包”（部分精简版 Windows 没有），或降低清晰度和帧率再试。
:::

## 常见问题

**触发后提示“请先在设置中启用对应插件”？**
到「设置」→「插件」勾选对应插件并保存。

**保存 GIF 失败怎么办？**
弹窗会告诉你原始 MP4 的位置，可以直接取用。

**手势触发后截图里不想带上轨迹？**
轨迹显示层会在截图时临时隐藏，截完自动恢复，不会出现在贴图里。
