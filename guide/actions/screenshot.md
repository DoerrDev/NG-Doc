# 区域截图

用手势或快捷键框选屏幕上的一块区域，标注后复制、保存，或者直接贴到屏幕上。装好就能用，不需要额外开启。

## 设置步骤

1. 新增或编辑一条手势，在「动作」里点「截图」。
2. 设置触发方式，例如一个鼠标手势，或者在「快捷键」页录一个 `F1`。
3. 点「保存」，触发一次试试。

截图动作固定为松手后执行，「执行时机」不能选「画到即执行」。

## 框选区域

触发后屏幕画面会先被冻结，你看到的是触发那一刻的画面。

- **拖选**：按住左键从一个角拖到对角，松开完成框选。
- **单击吸附**：鼠标移到窗口或界面元素（按钮、输入框、面板等）上时，它会被高亮，直接单击就选中这块区域。
- **取消**：按 `Esc` 或单击右键。

选区的宽和高都不能小于 16 像素。整个屏幕（含多显示器）都可以框选，截图按屏幕物理像素处理。

## 截图编辑

框选后进入编辑状态：选区外变暗，选区下方出现工具栏。

- 拖动选区边缘或四角的控制点可以调整大小，拖动选区内部可以移动位置。
- 一旦开始标注，选区就会锁定，不能再调整大小和位置。

工具栏右侧有四个核心按钮：

| 按钮 | 快捷键 | 作用 |
| --- | --- | --- |
| 退出截图 | `Esc` | 放弃这次截图 |
| 贴到屏幕 | `Ctrl + T`，或「贴图」动作绑定的快捷键 | 把选区（含标注）变成一张[贴图](./pin) |
| 保存并退出 | `Ctrl + S` | 保存为 PNG 后退出 |
| 复制并退出 | `Ctrl + C`，或双击选区 | 复制到剪贴板后退出 |

保存时默认文件名带当前时间，例如 `NextGestures_2026-11-26_09-30-05.png`。

## 标注工具

工具栏左侧是标注工具，截图编辑和[贴图](./pin)里都可以使用：

| 工具 | 快捷键 | 用法 |
| --- | --- | --- |
| 矩形 / 椭圆 | `Ctrl + 1` | 拖出图形；再按一次在矩形和椭圆间切换，按住 `Shift` 画正方形或正圆 |
| 箭头 / 直线 | `Ctrl + 2` | 拖出线条；再按一次在箭头和直线间切换，按住 `Shift` 锁定 45° 角 |
| 画笔 | `Ctrl + 3` | 自由涂画 |
| 记号笔 | `Ctrl + 4` | 较粗的标记笔 |
| 马赛克 | `Ctrl + 5` | 涂抹处打码 |
| 文字 | `Ctrl + 6` | 点击位置输入文字，支持输入法；`Enter` 确定，`Shift + Enter` 换行 |
| 橡皮擦 | `E` | 擦除标注 |
| 撤销 | `Ctrl + Z` | 撤销上一步 |

- 工具栏有 8 种预设颜色（红、橙、黄、绿、蓝、紫、黑、白），也可以点调色板自定义颜色。
- 使用工具时，滚轮用来调节粗细（文字工具则调节字号）。
- 按 `Esc` 会依次确定正在输入的文字、取消画到一半的一笔、退出当前工具；没有可退的内容时才退出截图。

## 常见问题

**截图里会不会带上手势轨迹？** 不会。截图前轨迹层会临时隐藏。

**为什么截到的不是现在的画面？** 截图画面在触发时就已冻结，方便截取菜单、悬停提示等一动就消失的内容。

**想把截图一直放在屏幕上对照着看？** 按 `Ctrl + T` 贴到屏幕，见[贴图](./pin)。
