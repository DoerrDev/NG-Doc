# 区域录屏

用手势或快捷键框选屏幕上的一块区域，录成 MP4 视频或 GIF 动图。装好就能用，不需要安装 ffmpeg 等工具。

## 设置步骤

1. 新增或编辑一条手势，在「动作」里点「录屏」。
2. 设置触发方式，点「保存」。

录屏动作固定为松手后执行。

## 录制流程

1. 触发后，用左键拖选录制区域，也可以单击高亮的窗口或界面元素直接选中。按 `Esc` 或右键取消。
2. 选定后，区域周围出现蓝色边框，下方出现小工具栏。
3. 点带有当前设置的按钮（默认显示「原始 · 30 FPS」），选择清晰度和帧率。
4. 点「开始录制」，边框变红，按钮变为「停止录制」。
5. 录完点「停止录制」。
6. 在弹出的保存窗口里选择位置和格式。保存成功后会提示「录屏已保存」和文件路径。

点工具栏右侧的取消按钮或按 `Esc` 可以放弃录制，录制中取消不会保存任何内容。录制开始后不能再改清晰度和帧率。

## 清晰度与帧率

| 选项 | 说明 |
| --- | --- |
| 720p 流畅 | 画面最大 1280 × 720（竖屏区域相应转置），只缩小不放大 |
| 1080p 高清 | 最大 1920 × 1080，只缩小不放大 |
| 原始分辨率 | 默认值，保持选区原大小，最大 4096 × 4096 |
| 帧率 | 15 / 24 / 30 / 60 / 120 FPS，默认 30 FPS |

实际能达到的帧率取决于屏幕刷新率、选区大小和电脑性能。

## 导出与保存

- 默认文件名是当前日期时间，可选「MP4 视频」或「GIF 动图」，默认 MP4。文件名必须以 `.mp4` 或 `.gif` 结尾。
- MP4 为 H.264 编码，保持录制时的画面大小和帧率。
- GIF 是体积较小的预览版：画面最大 854 × 480，约每秒 10 帧，循环播放。
- 录屏只采集画面，不录制声音。
- 同一时间只能进行一个录屏任务。

::: warning 编码器启动失败
录屏使用 Windows 自带的媒体功能。如果提示启动编码器失败，检查系统是否安装了「媒体功能包」（部分精简版 Windows 没有），或降低清晰度和帧率再试。
:::

## 常见问题

**保存 GIF 失败怎么办？** 弹窗会告诉你原始 MP4 的位置，可以直接取用。

**录出来的帧率比选的低？** 选区太大或帧率太高时，电脑可能跟不上，试试降低清晰度或帧率。
