# 按下快捷键

让手势替你按下一个组合键，例如 `Ctrl + W` 关闭标签页、`Alt + 左方向键` 后退。界面里的动作类型叫「快捷键」。

## 设置步骤

1. 编辑手势，在「动作类型」中选择「快捷键」。
2. 在「组合键」一栏点击「录制快捷键」。方框里会显示 `ctrl`、`alt`、`shift`、`win` 四个修饰键标记，并提示「请按下组合键…」。
3. 在键盘上按下你想要的组合，例如先按住 `Ctrl` 再按 `W`。按下主键的瞬间录制就完成了，松开按键即可。
4. 方框里显示的就是录到的组合。不满意可点「重新录制」，或点旁边的「清除」图标清空。
5. 点「保存」。

录制过程中按钮变成「取消」；切换到别的窗口也会自动结束录制。

## 录制与支持的按键

一个快捷键由「若干修饰键 + 一个主键」组成。修饰键可以是 `Ctrl`、`Alt`、`Shift`、`Win`，也可以不带修饰键，只录一个主键（例如 `F5`）。

支持的主键：

- 字母 `A`–`Z`、数字 `0`–`9`
- `F1`–`F24`
- `Tab`、`Enter`、`Esc`、`Space`、`Backspace`、`Delete`、`Insert`、`Home`、`End`、`PageUp`、`PageDown`
- 四个方向键、`PrintScreen`、`CapsLock`
- 标点键：`-`、`=`、`,`、`.`、`/`、`;`、`'`、`[`、`]`、`\`、`` ` ``

媒体键、小键盘等不在上述范围内的按键会被忽略，不会被录进去，也不会生效。

录制时，这些按键会被 NextGestures 先截获，所以 `Win + 方向键`、已被其他软件占用的快捷键也能录到，而且录制期间不会触发它们。不过 Windows 不允许拦截 `Win + L` 和 `Ctrl + Alt + Delete`，这两个无法录制。

## 按键发到哪里

手势触发后，组合键会像你在键盘上亲手按下一样，发给当前处于前台、获得键盘焦点的窗口，而不是鼠标指针下方的窗口。如果你的手势需要作用于某个窗口，请先确保它是活动窗口。

## 测试按钮

点击「测试」会立即发送一次这个组合键。注意此时前台窗口就是 NextGestures 的设置窗口，所以按键会发给设置窗口本身，主要用来确认组合已录好、没有报错；想看真实效果，请保存后到目标程序里用手势试一次。

## 常见问题

**手势触发了，但目标程序没反应？** 先确认该组合键在目标程序里手动按下是否有效，以及前台窗口是不是你想操作的那个。

**录制时按了没反应？** 单独按下修饰键不会结束录制，需要再按一个主键。
