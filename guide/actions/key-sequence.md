# 按键序列

把你在键盘上按下的一串按键完整录下来，之后由手势原样重放，包括按键之间的停顿。它收在动作网格的「更多」里，名为「按键序列」。

适合一连串固定的按键操作，例如先 `Ctrl + A` 全选、再 `Ctrl + C` 复制，或在一个表单里依次按 `Tab` 和 `Enter`。只需要一个组合键时，用[发送按键](./hotkey)更简单。

## 设置步骤

1. 编辑手势，在「动作」里点「更多」，再点「按键序列」。
2. 点击「开始录制」。按钮会短暂显示「正在启动录制…」，随后方框里提示「正在录制，请按下所需按键，再点击停止。」。
3. 在键盘上依次按下需要的按键。按下和松开的每一步都会实时出现在列表里。
4. 点击「停止录制」（短暂显示「正在停止录制…」）。录到的内容会保存为这个手势的动作。
5. 点击「测试」，按钮上会显示倒计时并提示「请切换到目标窗口」。在倒计时结束前切换到你想操作的窗口，观察效果。确认后点「保存」。

## 录制内容

列表里每一行是一次按键事件：

| 内容 | 含义 |
| --- | --- |
| 按键名称 | 例如 `ctrl`、`a`、`enter`；小键盘按键显示为 `num 1` 这样的形式 |
| 「按下」/「松开」 | 这一步是按下还是松开 |
| 「间隔」 | 距离上一个事件过了多少毫秒，第一个事件没有间隔 |

列表只用来查看，不能逐行修改。要调整内容，点「重新录制」整段重录，或点旁边的「清除」图标清空。

- 回放时严格按录到的顺序和间隔重放，所以停顿的长短会被保留。你在两次按键之间想了多久，回放时就等多久；第一个按键之前的等待不计入。
- 如果停止录制时还有按键没松开，会自动补上「松开」。
- 按键一直按住产生的重复输入只算一次按下。
- 开始录制前就已经按着的键，不会被录进去。

## 注意事项

::: warning
录制只能在 NextGestures 设置窗口处于最前面时进行。如果中途切到别的窗口或设置窗口失焦，本次录制会被取消，并提示「设置窗口已失焦，本次录制已取消。」，需要重新开始。
:::

- 录制期间，你按下的键只会被记录，不会真正输入到设置窗口里。
- 没有录到任何按键就点停止，会提示「本次没有录到按键。」，原有内容不变。
- 测试时必须在倒计时结束前离开设置窗口，否则会提示「请在倒计时结束前切换到要测试的窗口」。
- 重放期间按键发给当前前台窗口。如果上一次重放还没结束，又触发了一次，新的这次会被拒绝。
- 之前版本保存的旧序列仍可使用，每一步之间固定间隔 30 毫秒。
