# 快速反馈

遇到问题或有新想法，可以直接在软件里发给开发者，并在同一个页面查看开发者的回复。需要联网。

## 发送反馈

1. 点左侧导航的「设置」，切换到「反馈」页。
2. 在「昵称」中填写你的称呼，例如「张哥」，最多 64 个字符。
3. 在「新消息」框中写下需求或问题，最多 4000 个字符。建议写清使用场景、问题现象和你期待的结果。
4. 点「发送反馈」，或在输入框中按 `Ctrl + Enter`。

发送成功后输入框会清空，消息出现在「对话记录」里。发送过程中按钮显示「发送中…」。

- 昵称和内容都不能为空，否则会提示「请输入昵称」或「请输入反馈内容」。
- 发送失败会提示「发送失败：」加原因，输入的内容不会被清空，可以直接重试。
- 昵称在发送成功后会被记住，下次不用重新填。

## 查看对话与回复

「对话记录」按时间顺序显示你发出的消息和开发者的回复，开发者的消息标注为「开发者」，时间按你电脑的本地时间显示。还没有记录时显示「还没有对话记录，直接把你的想法发出来就行。」

页面打开时会自动加载，并每隔几秒自动更新一次，不用手动操作。右上角的状态文字会显示当前情况：

| 状态 | 含义 |
| --- | --- |
| 同步中 | 正在获取记录 |
| 已同步 | 获取成功 |
| 同步失败 | 获取失败，下方会显示「加载失败：」和原因 |

想立刻更新，点「对话记录」标题行的「刷新」图标。

## 开发者回复的提醒

软件在后台会定期检查是否有开发者的新回复。有未读回复时：

- 左侧导航的「设置」按钮上出现小圆点，鼠标停在按钮上会提示有几条来自开发者的新消息；
- 设置窗口里的「反馈」页签上也出现小圆点。

打开「反馈」页并成功加载后，这些回复会被标记为已读，小圆点随之消失。

## 发送了哪些数据

- 你填写的昵称和反馈内容；
- 一个由本机生成的匿名标识。它是对电脑系统中的机器码做哈希后得到的字符串，不包含原始机器码，用来把同一台电脑的对话归在一起；
- 软件的版本号和操作系统类型（Windows）。

软件运行期间还会定期向同一服务器发送状态检查（带上述匿名标识、版本号和系统类型），同时查询是否有未读回复。

::: warning 隐私提示
反馈内容会发送到开发者的服务器并保存，请不要在里面写密码、密钥等敏感信息。
:::

## 常见问题

**显示「同步失败」或「发送失败」？** 请检查网络连接。反馈功能依赖网络，请求超时时间较短，网络不稳定时可能失败，稍后点「刷新」或重新发送即可。

**断网会影响手势功能吗？** 不会。联网失败只影响反馈、提醒和检查更新，手势照常使用。
