# 快速开关手势

需要临时用回普通鼠标操作时，可以一键关闭全部手势，用完再打开。开关有三种方式：主窗口右上角的开关、托盘菜单、自定义的全局快捷键。

## 三种开关方式

| 方式 | 位置 |
| --- | --- |
| 主窗口开关 | 主窗口右上角的「手势总开关」，开着时显示「手势已启用」，关着时显示「手势已停用」，点一下即可切换 |
| 托盘菜单 | 右键任务栏托盘图标，勾选或取消勾选「启用手势」 |
| 全局快捷键 | 在「设置」→「触发与识别」页的「开关手势快捷键」中录制，在任何窗口下按下都会切换 |

三处状态是同步的：用其中一处切换后，其他两处会立刻跟着变化。

## 设置开关手势快捷键

1. 点主窗口右上角的「设置」，进入「触发与识别」页，滚动到底部找到「开关手势快捷键」。
2. 点「录制快捷键」，按下想用的组合键，例如 `Ctrl + Alt + G`。
3. 点「保存」。
4. 在任意窗口按下这个组合键，试试能否切换。

- **默认值**：没有默认快捷键，显示「尚未录制」。不录制就只能用主窗口开关或托盘菜单。
- 组合里需要有一个普通键（字母、数字、功能键等），只按 `Ctrl`、`Alt`、`Shift`、`Win` 这类修饰键不会生效。
- 已录制后，按钮变为「重新录制」，旁边的「清除」可以取消这个快捷键。
- 录制过程中按下的键不会触发其他程序的快捷键。

## 关闭后会怎样

每次切换，屏幕上会短暂弹出一条提示：「手势已启用」或「手势已停用」。提示的字体、颜色和位置沿用「触发提示」页的设置。

关闭后，手势、边角触发、滚轮触发等都不会再被拦截，鼠标按键和滚轮回到系统和各程序本来的行为。

::: warning 重启后会恢复为启用
总开关的状态不会保存。每次启动 NextGestures，手势都是启用的；上次关闭手势后退出，再次启动时不会保持关闭。
:::

## 开机自启动

在「设置」→「关于」页勾选「开机自启动」即可，取消勾选则不再自启动。这一项勾选后立即生效，不需要点「保存」。

::: tip 与黑名单的区别
总开关会停用所有应用里的手势。只想让某个程序使用它自己的手势，请用[黑名单](../profiles/blacklist)。
:::

## 常见问题

**按了快捷键没有反应？** 先确认已经点了「保存」。如果这个组合键已被其他程序占用，可能注册不上，换一个组合再试。

**关闭手势后重启，为什么又开了？** 见上面的提醒，总开关不跟随重启保留。
