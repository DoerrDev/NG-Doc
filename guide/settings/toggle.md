# 开关手势与快捷键

需要临时用回普通鼠标操作，或者不想让 NextGestures 占用快捷键时，可以一键关闭，用完再打开。鼠标手势和快捷键分开控制。

## 开关鼠标手势

有三种方式，三处状态同步：用其中一处切换，其他两处立刻跟着变化。

| 方式 | 位置 |
| --- | --- |
| 主窗口总开关 | 左侧导航栏下方的开关，下面显示「已启用」或「已暂停」，点一下切换 |
| 托盘菜单 | 右键托盘图标，勾选或取消勾选「启用手势」 |
| 开关手势快捷键 | 在「设置」→「触发与识别」页录制，在任何窗口按下都会切换 |

![左侧导航栏下方的总开关](/images/ui/rail.png){.shot .small}

每次切换，屏幕上会短暂弹出「手势已启用」或「手势已停用」，样式沿用「触发提示」页的设置。

关闭后，鼠标手势、滚轮手势、边角手势都不再拦截，鼠标按键和滚轮回到系统和各程序本来的行为。

::: warning 重启后会恢复为启用
总开关的状态不会保存。每次启动 NextGestures，手势都是启用的。
:::

## 暂停快捷键

总开关只管鼠标手势，不影响[快捷键触发](../triggers/hotkey)。要临时停用 NextGestures 注册的所有快捷键：

1. 右键托盘图标，勾选「暂停快捷键」。屏幕提示「快捷键已暂停」。
2. 用完后再点一次取消勾选，提示「快捷键已恢复」。

暂停期间：

- 所有手势快捷键和「开关手势快捷键」都会释放，其他程序可以正常使用这些按键。
- 鼠标手势不受影响，仍由「启用手势」单独控制。
- 恢复时如果有组合键已被别的程序占用，提示里会列出这些组合键。

## 设置开关手势快捷键

1. 点左侧导航的「设置」，在「触发与识别」页找到「开关手势快捷键」。
2. 点「录制快捷键」，按下想用的组合键，例如 `Ctrl + Alt + G`。
3. 设置会自动保存。在任意窗口按下这个组合键，试试能否切换。

- **默认值**：没有默认快捷键，显示「尚未录制」。
- 组合里需要有一个主键（字母、数字、功能键等），只按修饰键不会生效。
- 已录制后，按钮变为「重新录制」，旁边的「清除」可以取消这个快捷键。
- 它不能和任何手势的快捷键相同。

## 托盘菜单

右键托盘图标，菜单里有：

| 菜单项 | 作用 |
| --- | --- |
| 设置 | 打开主窗口 |
| 启用手势 | 勾选 / 取消勾选来开关鼠标手势 |
| 暂停快捷键 | 勾选后暂停所有快捷键 |
| 退出 | 彻底退出 NextGestures |

## 开机自启动

在「设置」→「关于」页勾选「开机自启动」即可，取消勾选则不再自启动。开机启动时 NextGestures 直接进入托盘，不弹出主窗口。

::: tip 只想停用某个程序里的手势？
总开关会停用所有程序里的鼠标手势。只想让某个程序使用它自己的手势，请用[交给程序自带手势](../profiles/passthrough)。
:::

## 常见问题

**按了开关手势快捷键没有反应？** 如果这个组合键已被其他程序占用，可能注册不上，换一个组合再试；另外检查托盘菜单里「暂停快捷键」是否被勾选。

**关了总开关，快捷键还能触发手势？** 是的，总开关只管鼠标手势。要停用快捷键，请勾选托盘菜单的「暂停快捷键」。

**关闭手势后重启，为什么又开了？** 总开关的状态不跟随重启保留，见上面的提醒。
