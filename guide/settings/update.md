# 版本与更新

左侧导航栏最下方显示当前版本号，例如 `v1.2.5`。

## 查看发布说明

点击版本号，会打开版本窗口：

![版本窗口](/images/ui/version-dialog.png){.shot .mid}

- 上半部分是当前版本的发布说明，列出这个版本新增和修复的内容。
- 下半部分是检查更新的结果。

## 检查与安装更新

NextGestures 启动时会在后台自动检查 GitHub 上的最新版本；打开版本窗口时也会再检查一次。

| 状态 | 含义 |
| --- | --- |
| 正在检查更新… | 正在获取最新版本信息 |
| 已是最新版本。 | 当前就是最新版本 |
| 发现新版本 vX.Y.Z | 有可用更新，下方显示新版本的发布说明 |
| 检查更新失败，请稍后重试。 | 网络问题等原因导致检查失败，可以点「重新检查」 |

发现新版本时，版本号旁会出现小圆点。打开版本窗口，点「立即更新」，NextGestures 会下载并安装新版本，完成后自动重启。下载安装期间按钮显示「下载安装中…」。

## 升级后的配置

- 升级会保留你所有的手势、配置组、AI 动作和设置。旧版本的「黑名单」会自动转换为[交给程序自带手势](../profiles/passthrough)的程序配置组，旧的 AI 设置会自动迁移到「AI 动作」页。
- 如果你用较新版本保存过配置，又换回了旧版本，旧版本不认识的动作会显示为「当前版本不支持此动作」并暂停，其他手势照常工作，原始配置也会保留。升级回支持它的版本即可恢复。

## 常见问题

**一直显示检查更新失败？** 检查网络能否访问 GitHub。也可以直接到 [GitHub Releases](https://github.com/DoerrDev/NextGestures/releases/latest) 下载最新安装包覆盖安装。

**更新后开机自启动的行为没变？** 新版本开机启动会直接进入托盘。如果是旧版本设置的开机启动项，到「设置」→「关于」取消勾选「开机自启动」再重新勾选一次即可。
