# 轨迹与提示外观

画手势时屏幕上会显示轨迹，命中后会弹出动作名称的提示。它们的样式在「设置」的「轨迹外观」和「触发提示」两页调整，不影响识别。

点左侧导航的「设置」打开设置窗口。所有改动都会自动保存并立即生效，看到满意的效果后点「关闭」即可。

## 轨迹外观

![轨迹外观设置页](/images/ui/settings-trail.png){.shot .mid}

| 选项 | 说明 |
| --- | --- |
| 安静模式（隐藏轨迹和命中提示） | 勾选后既不显示轨迹，也不弹出命中提示，手势照常执行 |
| 显示手势轨迹 | 是否显示轨迹；开启安静模式时不可选 |
| 效果预览 | 用当前设置画出的示例轨迹，改动后实时更新 |
| 轨迹颜色 | 轨迹的颜色 |
| 未识别颜色 | 松手后没有匹配到任何手势时，轨迹显示的颜色 |
| 轨迹粗细 | 1 到 16 |
| 辉光颜色 | 轨迹外围发光的颜色 |
| 辉光强度 | 0 到 40，0 表示不发光 |

每个颜色选项都可以直接输入颜色值、点色块打开取色器、点下方 8 个常用色，或者用「屏幕取色」从屏幕上吸取颜色。

## 触发提示

手势命中、切换总开关等时候，屏幕上会短暂弹出一行文字提示。

![触发提示设置页](/images/ui/settings-hint.png){.shot .mid}

| 选项 | 说明 |
| --- | --- |
| 置顶显示 | 提示显示在所有窗口最上层，不被其他窗口遮挡 |
| 字体大小 (px) | 12 到 48 |
| 字体颜色 | 提示文字的颜色 |
| 水平位置 X (px) | 以屏幕中心为原点，正数向右 |
| 垂直位置 Y (px) | 以屏幕中心为原点，正数向下 |

在这一页调整时，屏幕上会显示一条预览提示，位置和样式随设置实时变化。页面底部会显示当前虚拟桌面的尺寸，供你确定位置范围。

## 关于

「关于」页可以开关「开机自启动」，并显示「配置文件」的位置。所有手势、配置组、AI 动作和设置都保存在这个文件里，备份它就能备份全部配置。

![关于页](/images/ui/settings-about.png){.shot .mid}

::: warning 分享配置前
配置文件里保存着你的 AI 服务 API 密钥。把配置文件发给别人之前，请先删掉密钥。
:::
