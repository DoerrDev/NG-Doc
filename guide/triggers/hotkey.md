# 快捷键触发

不想用鼠标时，可以给手势设置一个全局快捷键，例如 `F1` 或 `Ctrl + Alt + T`。在任何窗口按下它，就执行这条手势的动作。

快捷键和鼠标手势是同一条手势的两种触发方式，共用下方的同一个动作：可以只设置快捷键，也可以两种都设置。

## 设置步骤

1. 在「手势」页选中配置组，新增或编辑一条手势。
2. 在触发方式里切换到「快捷键」页。
3. 点「录制」，按下想用的按键或组合键。方框里先显示 `ctrl`、`alt`、`shift`、`win` 四个修饰键标记，按下主键的瞬间录制完成。
4. 选择动作，点「保存」。
5. 在任意窗口按下这个快捷键，确认动作被执行。

录好后点「重新录制」可以重录，点「清除」去掉快捷键。只设置了快捷键的手势，在清单的「轨迹」列显示为键盘图标。

## 可以用什么键

- 可以直接用 `F1` 这样的单个键，也可以组合 `Ctrl`、`Alt`、`Shift`、`Win`。
- 必须有且只有一个主键（字母、数字、功能键等），只按修饰键不算。
- 支持的主键与[发送按键](../actions/hotkey#录制与支持的按键)相同。

## 在哪里生效

- 快捷键按**当前前台程序**选择配置组：前台程序有程序配置组且里面有这个快捷键，就执行它；没有再找 Global。
- 同一个组合键可以在不同配置组里绑定不同动作，例如 `F1` 在 Global 里打开网页，在 Photoshop 里发送另一组按键。
- 同一个配置组里不能有两条手势使用同一个快捷键，也不能和[开关手势快捷键](../settings/toggle)相同，保存时会提示。
- 被设为[交给程序自带手势](../profiles/passthrough)的程序里，快捷键不会执行动作。
- 停用的手势，快捷键也随之失效。

## 什么时候执行

动作在你**松开快捷键**之后才执行，这样 `Ctrl`、`Alt` 等修饰键不会干扰动作本身（例如动作要发送的组合键）。

- 按住超过约 2 秒才松开，本次不会执行。
- 按下到松开期间切换了前台窗口，本次也不会执行。

## 注意事项

::: warning 快捷键会被 NextGestures 独占
快捷键是向 Windows 注册的全局热键。注册成功后，无论当前是哪个程序，这个组合键都会先被 NextGestures 收走，其他程序收不到。即使它只绑定在某个程序配置组里，在别的程序里按下也只是被吞掉、不执行任何动作。请避免占用你在其他软件里常用的按键。
:::

- 如果组合键已经被别的程序注册，NextGestures 收不到它。编辑面板会提示「这个组合键已被其他程序占用，NextGestures 收不到。换一个组合键试试。」，清单里的快捷键标签也会显示为警示样式。
- 录制时按键由 NextGestures 先截获，所以即使是已被其他软件占用的组合也能录进来，但保存后能否生效取决于是否被占用。
- 左侧导航的总开关只停用鼠标手势。要临时停用所有快捷键，右键托盘图标勾选「暂停快捷键」，见[开关手势与快捷键](../settings/toggle)。

## 常见问题

**按了快捷键没反应？** 依次检查：是否已点「保存」；快捷键标签是否显示被占用；当前前台程序是否被设为交给程序自带手势；托盘菜单里「暂停快捷键」是否被勾选；按键时间是否过长。

**快捷键绑在 AI 动作上，没有取到选中的文字？** AI 动作会对前台窗口模拟 `Ctrl + C` 取词，请先在目标程序里选中文字，再按快捷键，见 [AI 动作](../ai/)。
