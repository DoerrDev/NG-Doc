# 边角触发

把鼠标移到屏幕的某条边或某个角，再通过滚轮、单击或停留来执行动作，不需要按住任何触发键。

## 可用的区域

共 8 个区域：「左上角」「上边」「右上角」「右边」「右下角」「下边」「左下角」「左边」。

- 边只有贴着屏幕最外侧约 3 像素的一条细线，鼠标要顶到屏幕边缘才算。
- 角是沿着两条边各延伸约 32 像素的一小段，贴着边滑进这一段就算角。
- 多显示器时，每块显示器单独判断。两块显示器相接的那一侧不算边，只有朝向桌面最外侧的边和角可以使用。

## 设置步骤

1. 打开主窗口，选中要配置的配置组，点「新增手势」。
2. 在「触发键」下拉框里选一个边角，例如「右上角」。
3. 在「边角动作」里选择触发方式（见下表）。
4. 填写「手势名称」，在「动作」里设置要执行的内容，点「保存」。
5. 把鼠标移到对应边角，做出刚才选的操作，确认动作被执行。

## 边角动作

| 选项 | 怎么触发 | 是否需要录制 |
| --- | --- | --- |
| 滚轮（录制） | 鼠标停在边角上滚动滚轮 | 需要 |
| 右键单击 | 在边角原地单击鼠标右键 | 不需要 |
| 中键单击 | 在边角原地单击鼠标中键 | 不需要 |
| 侧键 1 单击 | 在边角原地单击侧键 1 | 不需要 |
| 侧键 2 单击 | 在边角原地单击侧键 2 | 不需要 |
| 停留 | 鼠标在边角停住不动 | 不需要 |

### 滚轮

点「点击开始录制」，把鼠标移到目标边角，滚动滚轮；停下约 0.4 秒后录制结束。滚轮方向是录制内容的一部分：向上滚、向下滚，或者先上后下，都是不同的手势。同一方向连续滚多格只算一次，方向反转才会多记一步。

触发后，这次滚动不会再传给下面的窗口，所以页面不会跟着滚动。

### 单击

选好单击的按键后无需录制，保存即可使用。也可以点「重新录制」，然后在任意边角原地单击右键、中键或侧键，界面会自动识别成对应的边角单击。

- 单击要在原地完成。按住按键后拖动超过「进入手势的最小距离」，这次操作会原样交还给系统，不会触发。
- 如果该边角没有匹配的单击手势，你的单击会照常发给当前窗口，不受影响。
- 边角单击不需要在设置的「可用触发键」里勾选对应按键。
- 左键不支持边角单击。

### 停留

在「停留时长（毫秒）」里填写时间，范围是 100 到 10000 毫秒，默认 600。鼠标进入边角后持续停留到这个时间就会触发，一次只触发一次；要再次触发，需先移出边角再回来。停留手势不能录制，也不需要按任何键。

## 使用细节

- 单击和停留手势的「触发时机」下拉框锁定为「松开触发键后执行」，实际上单击在松开按键时执行，停留在停够时长时执行。滚轮手势可以选「画到匹配立即执行」，滚出的方向与录制的一致时就立即执行，一次滚动只执行一次。
- 手势总开关关闭时，边角手势同样不生效；当前窗口属于黑名单中的程序时也不会触发。
- 当前窗口是全屏程序（例如全屏游戏、全屏视频）时，边角手势不会接管鼠标。
- 在边角滚动滚轮的过程中，如果按下任何鼠标键，这次滚轮手势会被放弃。
- 边角手势可以放进 Global，也可以放进某个程序的配置组，后者优先。详见 [Global 配置组](../profiles/global) 和 [其他配置组](../profiles/apps)。

## 常见问题

**滚轮或单击没有反应。** 确认鼠标确实贴到了屏幕最外侧；多显示器时确认这一侧没有相邻显示器；确认当前不是全屏程序、手势总开关已启用，且该程序不在 [黑名单](../profiles/blacklist) 中。

**停留总是不触发。** 鼠标需要在边角里完全停留满设定的时间，中途移出再进入会重新计时。时间设得太短也容易在经过边角时误触发。
